# DocearReminder Build Instructions

## How to Build

### Method 1: Using Batch File (Recommended)

Just double-click `Build.bat` to build automatically.

### Method 2: Using PowerShell Script

Right-click `Build.ps1`, select "Run with PowerShell", or execute in PowerShell:

```powershell
.\Build.ps1
```

### Method 3: Using Visual Studio

1. Open `DocearReminder.sln` with Visual Studio
2. Select `Release` configuration and `Any CPU` platform
3. Right-click solution, select "Rebuild Solution"

## Output Directory

Build output will be in:
```
D:\Dropbox\Software\DocearReminder
```

## Build Script Features

- Automatically find and use MSBuild to build project
- **Will NOT delete any existing files** - only overwrites program files
- Automatically copy resource files (Skins, Sounds, Demo, etc.)
- Show build progress and results
- Count generated files and total size

## Notes

1. Ensure Visual Studio 2019 or later, or .NET Framework 4.8 is installed
2. **No files will be deleted** - existing user files are safe
3. Program files will be overwritten with new versions
